# SimulateFuture：用智能体模拟 AI 时代的人和人

用生成式智能体（类似"斯坦福小镇"）模拟 AI 时代里人和人之间的互动会怎么变：在大学里，在招聘中，在职场的第一年。

定位是**社会风洞，不是天气预报**。我们不追求说出"2030 年会怎样"，而是改一条规则，看人和人之间会发生哪些连锁反应。

---

## 1. 这种模拟有什么意义

**给不了的：** 带具体数字的预测，比如"2030 年有多少学生会怎样"。大模型的知识全部来自过去，模拟结果在很大程度上反映我们写进去的假设。

**给得了的：**

1. **发现没想到的连锁反应。** 一条规则改变后，信任、合作、竞争会往哪个方向走。
2. **比较不同方案。** 不同的制度设计里，谁受益、谁吃亏、副作用在哪。
3. **逼自己把假设写清楚。** 所有假设都在配置里，可以逐个质疑、逐个调整。

**怎么判断它有没有意义：先回测。** 每个版本都先重演一段已经知道答案的历史。重演不出来，就不要相信它对未来的结论。

---

## 2. 两个研究版本

| 版本 | 研究对象 | 核心问题 | 回测基准 |
|---|---|---|---|
| [版本一：大学](docs/university.md) | 大学生、老师、校招雇主 | AI 禁不住的前提下，大学最后会变成什么？ | 2023 年春季学期，ChatGPT 刚进校园 |
| [版本二：职场新人](docs/early-career.md) | 工作 0 到 3 年的人、老员工、经理 | AI 能做新人的活以后，新人怎么成长为老手？ | 2023 到 2025 年，AI 影响大的职业里新人招聘下降 |

两个版本前后相连：版本一的毕业生，就是版本二的新人。可以先做其中一个，以后把来源大学作为变量接到职场版本里。

---

## 3. 怎么搭

- **先做纯文本版，不做地图。** Python 加 Claude API。地图是给人看的，不产生洞察。
- **模型做决策，代码算后果。** 成绩、能力增长、录用和晋升规则写成确定性代码，不让模型编。这样不同条件之间的差异才来自制度，而不是来自模型的随机性。
- **事件驱动推进。** 只模拟关键时刻，比如上课、交作业、考试、代码评审、考核、求职，不逐小时推进。
- **多跑几次。** 每个条件跑多个随机种子，比较结果的分布，而不是看单次结果。
- **结束时采访。** 模拟结束时逐个"采访"智能体，收集定性材料。
- **运行需要 Anthropic API key。** 日常决策用小模型，反思和关键对话用大模型，以控制成本。

---

## 4. 已知风险

- **智能体太像、太和气。** 大模型天然趋同。人设里要强行拉开差异，加入固执度和噪声。
- **智能体太能干。** 大模型本身什么都会，扮演学生或新人时会表现得太强。"会不会"要由代码里的能力值决定，不由模型自己决定。
- **智能体会背社论。** 问它对 AI 的看法，它会复述评论文章。提示词要逼它做第一人称的具体决定，比如"这个问题我先问同事还是先问 AI"。
- **结果主要反映假设。** 所有假设写在配置里，做敏感性分析，看结论对哪些假设最脆弱。
